In this project, SQL is used to create all five necessary tables (Users, Bids, Items, Orders, and Carts). The insert statements that you see after that are what populate the tables with dummy data that we can use to test out the system and make sure that everything works smoothly. We also have two join queries as well, and the first one allows us to see the details of the user and their bid as well for an item (tracked by itemid). The second query allows us to see a user's details and their cart so that we can know which cart belongs to which user. We have our aggregate query next, which allows us to group orders based on the date that they were placed, so that we can see how many orders are made each day or at a time. Our subquery allows us to see items that have bids over a certain amount. Finally, we have an index on the system that allows us to query a specific item listing based on an itemid and a userid index combo.
